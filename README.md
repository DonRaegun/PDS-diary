# 플랜두씨 다이어리 1 (과제 6)

계획(Plan) → 실제로 한 일(Do) → 돌아보기(See)가 이어지는 다이어리. 로그인 없음, 자료는 서버의 SQLite DB(`data/diary.sqlite`)에 저장됩니다.
외부 패키지 없이 Node.js(22.5+, `node:sqlite`)만 씁니다. 비밀키·환경 비밀값은 사용하지 않습니다.

```bash
npm start          # http://localhost:3000
npm run seed       # 빈 DB일 때만 내 시작 자료를 넣음
npm test           # API·DB 제약·스키마 계약 테스트
```

환경 변수: `PORT`(기본 3000), `PDS_DB`(DB 파일 경로). 배포할 때는 DB 파일이 사라지지 않는 디스크(영구 볼륨)를 `PDS_DB`로 지정해야 새로고침·재시작 뒤에도 자료가 남습니다.

## 짧은 확인 방법

**① 어디로 가나요**
배포 주소(제출 시 기입) 또는 로컬 `http://localhost:3000`을 새 시크릿 창에서 엽니다. 계정·로그인은 필요 없습니다.

**② 세 단계 안에 무엇을 하나요**
1. 「할 일」 탭에서 아무 미완료 할 일의 **완료** 버튼을 빠르게 두 번 누릅니다.
2. 「돌아보기」 탭에서 **완료 수** 숫자를 눌러 근거 목록으로 이동합니다(한 번만 늘었는지 확인).
3. 새로고침(F5)하고, 위쪽 **내보내기(JSON)** 를 눌러 파일 한 개를 받습니다.

**③ 무엇이 보이면 통과인가요**
- 첫 화면 맨 위에 「지금은 로그인이 없어 링크를 아는 사람은 누구나 볼 수 있습니다. 남이 봐도 괜찮은 내용만 넣으세요」가 보입니다.
- 토스트에 「완료로 바꿨습니다」, 이어서 「이미 완료로 기록되어 있습니다」가 뜨고, 완료 수는 정확히 1만 늘며 완료 기록(`completions`)은 1건입니다.
- 완료 수를 누르면 나오는 목록 개수가 돌아보기 숫자와 같습니다. 새로고침 뒤에도 값·ID·날짜·분 단위가 같습니다.
- 내보낸 JSON 한 개에 계획·수정 이력·할 일·태그·실행 기록·완료·돌아보기 자료가 모두 들어 있습니다.
- 할 일 이름에 `<script>alert(1)</script>`를 넣어도 실행되지 않고 글자 그대로 보입니다.

**④ 안 될 때는 무엇이 보이나요**
- 입력이 잘못되면 화면 오른쪽 아래에 빨간 토스트로 이유(예: 「종료일은 시작일보다 빠를 수 없습니다」)가 뜨고 저장되지 않습니다.
- 서버에 닿지 못하면 화면에 「화면을 불러오지 못했습니다: …」와 **다시 시도** 버튼이 보입니다.
- 없는 주소는 `{"error":"없는 주소입니다"}`(404), 허용되지 않는 요청은 405로 응답합니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `db.js` | SQLite 스키마(표·제약·유일 인덱스) |
| `server.js` | HTTP API + 정적 파일 + 보안 헤더(CSP 등) |
| `public/` | 화면(순수 JS, `innerHTML` 미사용) |
| `contracts/pds-schema-v2.json` | 최종 표·항목·관계·날짜 규칙 (테스트가 실제 DB와 대조) |
| `seed.js` | 내 시작 자료 |
| `test/` | `node --test` 테스트 |

## 핵심 규칙
- **수정 이력**: `plans`는 현재 값, `plan_revisions`는 처음 값과 모든 수정본(덮어쓰지 않음). 계획 ID는 그대로.
- **중복 완료 방지**: ① `Idempotency-Key` 재사용, ② 이미 완료면 무시, ③ DB 부분 유일 인덱스 `uq_completions_active`. 버튼 잠금에 의존하지 않습니다.
- **실행 기록**은 `runs` 표에 따로 저장되고 `tasks` 값을 건드리지 않습니다.
- **시간**: 달력 날짜는 서울 `YYYY-MM-DD`, 시각은 UTC로 저장해 서울 시각으로 표시, 시간 양은 분.
- **정렬**: 화면에 기준을 적고, 같은 값이면 마감일 → 우선순위 → 등록 번호 순. 거르기·정렬은 서버(SQL)에서 합니다.
- **돌아보기**: 계획 수 = 지우지 않은 할 일 수, 지연 = 미완료이면서 마감일 < 오늘(서울), 막힘 = 막힌 이유가 적힌 실행 기록이 있는 할 일 수. 숫자를 누르면 같은 조건의 목록으로 갑니다.
